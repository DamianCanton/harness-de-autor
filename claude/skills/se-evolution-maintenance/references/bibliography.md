## Technical debt
- [known] Cunningham, W. (1992). The WyCash Portfolio Management System. *OOPSLA '92 Experience Report*. Origin of the "debt" metaphor: shipping first-time code is like going into debt; interest is paid on every later change until repaid.
- [known] Fowler, M. (2009). Technical Debt Quadrant (deliberate/inadvertent × prudent/reckless). martinfowler.com/bliki/TechnicalDebtQuadrant.html.
